# 🧩 Low-Level System Design (LLD) Examples

This document provides a **comprehensive list of Low-Level Design (LLD)** examples categorized by type — suitable for interview preparation or hands-on design practice.

---

## 1. 🧱 Object-Oriented Design (OOP-based) Systems

Focus on **class design, relationships, and design patterns**.

- Parking Lot System
- Library Management System
- ATM / Banking System
- Vending Machine
- Elevator System
- Snake and Ladder Game
- Splitwise System
- Cab Booking System (like Uber/Ola)
- Hotel Management System
- Movie Ticket Booking System (BookMyShow)
- Flight Reservation System
- Restaurant Management System
- Inventory Management System
- Coffee Machine
- Car Rental System (Zoomcar)
- Online Shopping Cart
- Order Management System (Flipkart/Amazon)
- Tic Tac Toe / Chess / Ludo Game
- File Storage System (Google Drive)
- Zoo Management System
- Banking Transaction System
- Task Management App (Trello-like)
- Expense Tracker
- Calendar / Meeting Scheduler
- Digital Wallet System (Paytm/PhonePe)

## 2. ⚙️ Concurrency and Thread-Safe Designs

Focus on **synchronization, locking, and concurrent access**.

- Thread-safe Logger System
- Rate Limiter (Token Bucket / Leaky Bucket)
- Cache System with Eviction (LRU, LFU)
- Producer-Consumer Problem
- Thread Pool Executor
- Message Queue Implementation
- Job Scheduler
- Dining Philosopher Problem
- Elevator System with Multi-threading
- Concurrent Order Processing System

## 3. 🧮 Data Structure-Heavy LLDs

- LRU / LFU Cache

- URL Shortener
- Text Editor Undo/Redo System
- Notification Service
- File System Simulation
- Leaderboard / Ranking System
- Document Version Control System (Git-like)
- Search Suggestion System
- Feed Ranking System (Twitter/LinkedIn)

## 6. 🧠 Design Pattern-Focused Mini Projects

## 💡 Interview Preparation Tips

When designing any LLD, focus on:
- Class Diagrams
- Relationships (composition, inheritance, aggregation)
- SOLID Principles
- Thread Safety
- Design Patterns
- Sample APIs and Sequence Flow
